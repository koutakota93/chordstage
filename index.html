                曲を追加

                コード譜サイトの曲を追加する

                対応: ChordWiki(「編集」のソース)/ U-フレット / リンネのコードブック(表示中のコード譜)/ J-Total・ほかのサイト(譜面の文字を選択してから押す)

                1. コード譜サイトの曲のページを開く(ChordWikiは別ウィンドウで開くと、2画面で並べて操作できます)
                2. ブックマーク「→ChordStage」を押す(下の初回設定を参照)。このアプリに自動で追加され、ChordWikiの画面はそのまま残ります
                初回だけ: ブックマークを作る
                1. 下の「コードをコピー」を押す
                2. Chromeで任意のページをブックマークに追加し、ブックマークを編集して、名前を「→ChordStage」、URLを貼り付けたコードに変える
                3. 使うとき: コード譜サイトの曲ページで、アドレスバーに「→ChordStage」と入力し、候補に出るブックマークを選ぶ
                →ChordStage(PCではこのリンクをブックマークバーにドラッグ)
                うまくいかない場合: 手動で貼り付ける

                ChordWikiの「編集」画面のソースを全選択してコピーし、このアプリに戻ると自動で貼り付けます。貼り付かない場合は「クリップボードから貼り付け」を押してください。

                ペダル・キーの割り当て

                「＋ 割り当て」を押してから、ペダルを踏む(またはキーを押す)と、その信号を動作に割り当てます。

                ペダル/キーボード: → ↓ PageDown Enter で次へ、← ↑ PageUp で前へ。自動モードでは Space で開始/停止。

                バックアップ / 復元

                Googleドライブ

                ドライブの最新の内容を反映してから、端末の内容を保存します。曲・メモ・セットリストが対象です。

                個別の操作(履歴つきバックアップ)
                  初回設定(クライアントIDの登録)
                  1. Google Cloud コンソールでプロジェクトを作り、「Google Drive API」を有効にする
                  2. OAuth 同意画面を設定(外部)し、自分のGoogleアカウントを「テストユーザー」に追加する
                  3. 「認証情報」→「OAuth クライアントID」→ 種類は「ウェブ アプリケーション」。「承認済みの JavaScript 生成元」にこのアプリのURL(https://…netlify.app)を追加
                  4. 表示された「クライアントID」を下に貼り付けて保存する
                  ファイル(設定不要)
